## Goal

Run only the FIC Research phase for the requested topic.

## Workflow

1. Read `.rules/base-rules.md`.
2. Read `.rules/fic-workflow.md`.
3. Read `.rules/fic/research.md` and follow it as the canonical procedure.
4. Read `PROJECT.md` if it exists.
5. Produce the required `.thoughts/shared/research/` artifact.

## Guardrails

- Do not plan, implement, or validate.
- Do not continue into the next FIC phase.
- Preserve the root `AGENTS.md`, `CLAUDE.md`, and `GEMINI.md` symbolic links.

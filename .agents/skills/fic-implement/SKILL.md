## Goal

Run only the FIC Implement phase for the requested topic.

## Workflow

1. Read `.rules/base-rules.md`.
2. Read `.rules/fic-workflow.md`.
3. Read `.rules/fic/implement.md` and follow it as the canonical procedure.
4. Read `PROJECT.md` if it exists.
5. Execute only the approved implementation slice.

## Guardrails

- Do not switch back into research or planning unless blocked.
- Do not validate beyond checks needed for the implemented slice.
- Do not continue into the next FIC phase.
- Preserve the root `AGENTS.md`, `CLAUDE.md`, and `GEMINI.md` symbolic links.

## Answers to Questions

### 1. `AGENTS.md` could be the entry point for CLAUDE or GEMINI? Or only for CODEX?
- **Answer**: `AGENTS.md` is a generic entry point often used for Codex (which doesn't have a standardized entry file like Claude). For **Claude Code**, the standard entry point is `CLAUDE.md`, and for **Gemini**, it's `GEMINI.md`. To ensure best compatibility across all three, the repository now includes `CLAUDE.md`, `GEMINI.md`, and `AGENTS.md`, all pointing to the same base entry configuration (`.rules/entry.md`).

### 2. Do I need a `.docs` directory? For what docs?
- **Answer**: Yes, to maintain a clean context for both humans and agents. While `.rules/` contains normative logic for the agent and `.thoughts/` captures transient work-in-progress, `.docs/` should house **stable, human-readable documentation**. This includes:
  - High-level architecture overviews.
  - Domain glossaries.
  - Local environment setup guides for humans.
  - Long-form context that doesn't need to be in the agent's immediate active rules but should be accessible on demand.
